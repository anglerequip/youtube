Privacy policy: CounterPhysical uploader

Last updated 20 November 2026.

The CounterPhysical uploader is used only by the owner of the CounterPhysical channel to upload, schedule and manage that channel's own videos.

What data it uses

With the owner's permission (Google OAuth), it uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails and publish times, and read basic statistics for the owner's own videos. It does not access anyone else's data.

How data is stored

The sign-in token is stored encrypted in the channel owner's private secret storage and is used only by the channel's own automation. No data is sold, shared with third parties or used for advertising.

Facebook

With the owner's permission, it uses the Facebook Graph API to publish the channel's own videos as reels on the CounterPhysical Facebook Page and to check that they were published. It does not read or store data about other people.

Deleting your data

The tool keeps no personal data about anyone except the owner's own access tokens. To remove its Facebook access, open Facebook Settings, then Business integrations (or Apps and websites), and remove "CounterPhysical uploader"; the token stops working at once. For any other deletion request, message the CounterPhysical Facebook Page and it will be handled within 30 days.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Through the CounterPhysical YouTube channel's About page.
